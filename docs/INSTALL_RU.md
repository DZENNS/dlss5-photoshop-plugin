# Установка: пошагово

**Плагин предназначен исключительно для Mac с Apple Silicon (M1 и новее). На Windows он НЕ портирован. Windows-сборки нет. На Intel Mac эта ARM64-сборка не работает.**

## 1. Что скачать

Откройте Releases этого репозитория → v0.9.4 → Assets → `DLSS5-Native-0.9.4-macOS-arm64-BYO-model.zip`.
Не выбирайте Source code, если нужна готовая программа. Дважды щёлкните ZIP в Finder. Внутри находятся:

- `DLSS5 Native.plugin` — уже скомпилированный плагин;
- `Configure.command` — добавление вашей модели в новую копию плагина;
- инструкции и лицензии.

Real-ESRGAN ×2 уже включён. Извлечённые веса NVIDIA не распространяются. Для режима DLSS сначала подготовьте модель по следующему пункту. Никакая платная подписка для локальных вычислений плагину не нужна.

## 2. Какая модель нужна

Поддерживаемый вариант для этой версии — **HT, 71 блок**. Нужна папка со следующими файлами непосредственно внутри:

```
NR.dlss/
  manifest.json
  weights.safetensors
```

Папка может называться `NeuralRendering.dlssmodel`: команда настройки переименует её копию в `NR.dlss`. Один файл `.safetensors` без соответствующего manifest не подходит. Small, SeedVR2, Stable Diffusion и модели апскейлеров вместо HT не подходят. Название папки не делает неподходящую модель совместимой.

### Вариант А — у вас уже есть собственный подготовленный пакет

Выберите его при запуске Configure.command. Если модель находится в вашем локальном приложении: Finder → правый клик по `.app` → «Показать содержимое пакета» → Contents → Resources → NR.dlss. Скопируйте **всю папку** в удобное место, например «Документы». Для собственной старой версии плагина путь также Contents/Resources/NR.dlss.

Используйте модель, которую вы вправе использовать. Репозиторий не предоставляет право распространять извлечённые веса NVIDIA.

### Вариант Б — подготовить пакет из собственной NVIDIA DLL

Это отдельный технический этап. Готовый плагин Python не использует, но инструмент подготовки модели требует Python 3.10+ и скачивает зависимости. Нужна законно полученная `nvngx_dlssnr.dll` **310.8.0.0**, поддерживаемая включённой версией конвертера. Не путайте её с `nvngx_dlss.dll` (Super Resolution) или `nvngx_dlssg.dll` (Frame Generation). Репозиторий не раздаёт DLL и не скачивает её автоматически.

1. Установите Python 3.10+ с python.org, если его ещё нет.
2. Скачайте исходники этого репозитория: Code → Download ZIP, распакуйте.
3. Откройте «Терминал» (Spotlight: Command+Пробел → Терминал).
4. Введите `cd ` с пробелом, перетащите распакованную папку исходников в окно Терминала и нажмите Enter.
5. Выполните по одной строке:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install ./Vendor/MLX-DLSS/python
```

6. Укажите реальный путь к своей DLL; кавычки сохраняйте, особенно при пробелах:

```sh
.venv/bin/mlxdlss-weights sha256 "/путь/к/nvngx_dlssnr.dll"
.venv/bin/mlxdlss-weights all "/путь/к/nvngx_dlssnr.dll" "$HOME/Documents/DLSS5-models"
```

7. Результат: `Документы/DLSS5-models/NeuralRendering.dlssmodel`. Используйте именно папку модели, не соседний safetensors для PyTorch.

Если инструмент сообщает неизвестный хеш/версию или ошибку структуры — не обходите проверку и не переименовывайте DLL. Эта версия конвертера не поддерживает произвольные новые сборки. Октябрьская Small не поддерживается плагином 0.9.4; обновление требует отдельного порта. Подготовка модели является вашей локальной операцией; соблюдайте условия полученного исходного ПО.

## 3. Добавить модель в готовый плагин

1. Оставьте `Configure.command` и `DLSS5 Native.plugin` рядом в распакованной папке релиза.
2. Создайте пустую папку на рабочем столе, например «DLSS5 готовый».
3. Дважды щёлкните Configure.command. Откроется Терминал и окно выбора папки.
4. В первом окне выберите **саму папку модели**, внутри которой manifest.json и weights.safetensors.
5. Во втором окне выберите папку «DLSS5 готовый».
6. Дождитесь сообщения `Configured plug-in`. Команда создаст там новую `DLSS5 Native.plugin`, добавит модель и заново подпишет пакет локально. Существующий плагин не перезаписывается.

В некоторых окнах Finder `.dlssmodel` показывается как пакет: для выбора используйте Command+Shift+G и введите полный путь к папке. Также можно запускать команду с двумя путями из Терминала:

```sh
"/путь/к/Configure.command" "/путь/к/NeuralRendering.dlssmodel" "/путь/к/пустой-папке"
```

Если появится запрос установки Apple Command Line Tools для codesign, установите их и повторите. Xcode для использования готового плагина не нужен. Локальная подпись не равна Developer ID и не является нотариализацией.

## 4. Установить в Photoshop

1. Сохраните документы и полностью закройте Photoshop через Photoshop → «Завершить Photoshop» (Command+Q).
2. В Finder откройте «Программы» → папку нужного Adobe Photoshop → Plug-ins.
3. Если здесь уже есть DLSS5, перенесите предыдущую копию **за пределы всех папок Plug-ins** для резервного хранения. Не держите две версии одновременно.
4. Скопируйте **настроенную** `DLSS5 Native.plugin` из «DLSS5 готовый» в Plug-ins. Это пакет: копировать нужно целиком. macOS может запросить пароль администратора.
5. Запустите Photoshop. Откройте фотографию, выберите обычный пиксельный слой. Меню Image → Mode: RGB Color, 8 Bits/Channel.
6. Откройте Filter → DLSS5 → DLSS5 Native. Это нативный фильтр, не панель в меню Plugins. Developer Mode UXP не требуется.

## 5. Если macOS блокирует запуск

Выпуск **без Developer ID и нотариализации**. После первой попытки загрузить плагин может появиться сообщение о непроверенном разработчике.

Откройте Apple → Системные настройки → Конфиденциальность и безопасность. Прокрутите до раздела «Безопасность». Если для DLSS5 есть «Всё равно открыть» / «Разрешить», нажмите и подтвердите. Затем полностью перезапустите Photoshop. Для Configure.command может потребоваться аналогичное разрешение после первой попытки открытия.

Название и наличие кнопки зависят от версии macOS. Если кнопки нет или политика организации запрещает сторонние плагины, обратитесь к администратору. Не отключайте Gatekeeper или SIP целиком. Не снимайте защиту у файлов неизвестного происхождения.

## 6. Первая обработка

1. Выберите Natural/Standard/Cinematic. Off не применяет DLSS.
2. Начните с 512 px; это разрешение вычислений, а не размер экспортируемого документа.
3. Нажмите «Превью» либо включите «Автоматически». Первый запуск может занять больше времени.
4. Сравните оригинал и результат, используйте масштабирование и перетаскивание.
5. Нажмите «Применить на новый слой». Исходный слой должен сохраниться.
6. Для Real-ESRGAN ×2 выберите соответствующий пункт; нужен слой во весь документ без активного выделения. При применении изменится Image Size всего документа. Перед применением сохраните PSD.

Двойной клик по держателю каждого ползунка сбрасывает только этот параметр. «Радиус деталей» — 4, остальные ползунки — 1. Между сеансами запоминается «Автоматически», наборы параметров сохраняйте в пресеты.

## 7. Типовые проблемы

- **Нет пункта в Filter:** проверьте папку именно запущенной версии Photoshop, ARM64, полный перезапуск, отсутствие дубликатов. Не устанавливайте в Windows.
- **Не найдена модель:** путь должен быть Contents/Resources/NR.dlss/manifest.json и weights.safetensors, без лишней вложенной папки.
- **Ошибка модели / несовпадение хеша:** заново подготовьте совместимый HT-пакет. Не смешивайте manifest и веса от разных конвертаций.
- **DLL не выбирается:** Configure принимает готовую папку модели. Сначала выполните пункт 2Б.
- **Результат не меняется:** Off или нулевая сила отключают DLSS. При выключенной автоматике нужно нажать «Превью».
- **Высокое потребление памяти:** уменьшите рабочее разрешение, отключите ×2 и закройте лишние документы. 1920 px тяжелее 512 px.
- **Нельзя выбрать ×2:** нужен полноразмерный слой без выделения; действуют ограничения размера изображения.
- **После обновления видна старая версия:** полностью завершите Photoshop и проверьте дубли в Plug-ins.

Для удаления завершите Photoshop, уберите пакет из Plug-ins и запустите Photoshop заново. Пользовательские модели и пресеты автоматически не удаляются.
